# HONDA Phone 1 - نسخه 3.0.0

این ZIP یک نسخه تمیز و هماهنگ از مرحله Phone 1 پروژه موتور است.

## نکته مهم نسخه‌ها
این نسخه عمداً روی Expo SDK 57 نگه داشته شده و نسخه‌های اصلی با همین SDK هماهنگ شده‌اند:
- Expo 57.0.22
- Expo Router 57.0.21
- React 19.2.3
- React Native 0.86.0
- Camera 57.0.5
- Location 57.0.17
- Sensors 57.0.3
- Status Bar 57.0.1

در این نسخه `react-dom` حذف شده و typed routes نیز خاموش است تا مسیر type-generation اضافی وارد اجرای اولیه نشود.

## نصب
فقط وارد این مسیر شو:
`mobile\phone1`

و یک بار اجرا کن:
`npm install`

بعد:
`npx expo start -c`

یا از فایل `RUN_HONDA.bat` در ریشه ZIP استفاده کن.

## امکانات فعلی Phone 1
- داشبورد افقی HONDA
- GPS و سرعت و مسافت
- شتاب‌سنج و وضعیت حرکت گوشی
- ارتباط محلی با ESP8266
- کنترل محلی فقط شارژر
- نمایش دما، LDR، FC-51، Ignition و وضعیت ESP
- دوربین جلو و عقب
- عکس گرفتن
- فیلم‌برداری تا 120 ثانیه
- تنظیم IP محلی ESP

## قرارداد فعلی ESP
IP پیش‌فرض: `192.168.1.50`

مسیر خواندن وضعیت:
`GET /api/v1/state`

مسیر کنترل شارژر:
`POST /api/v1/charger`

بدنه کنترل:
`{"on":true}` یا `{"on":false}`

## ایمنی پروژه
D8 / STOP فقط نشانگر STOP است و هرگز به‌عنوان قطع‌کننده موتور استفاده نمی‌شود.

این نسخه هنوز Backend، Phone 2، Telegram، Google Sheets، ThingSpeak و WebRTC را به عنوان مرحله‌های بعدی پروژه وارد نکرده است.
